# 按键与省电模式实施计划 V1.0

**目标：** 让 Waveshare ESP32-S3-Touch-AMOLED-1.75C 的 `BOOT` 与 `PWR` 两键均有可验证功能，并保持 Wi-Fi、OTA 与语音链路可用。

**硬件事实：** `BOOT` 接 ESP32 GPIO0；`PWR` 状态经板载 TCA9554 的 `EXIO4` 输入提供。AXP2101 的 `0x27` 寄存器中 `OFFLEVEL=11` 表示 10 秒硬关机，因此使用 `0x1C` 保留现有 1.5 秒 IRQ 配置。

## 实施步骤

1. 先运行 `scripts/test_ygsoul_button_contract.sh`，确认它因按键能力尚未实现而失败。
2. 在 `main/boards/waveshare/esp32-s3-touch-amoled-1.75/esp32-s3-touch-amoled-1.75.cc` 实现：
   - `BOOT` 短按维持现有语音开始/停止；长按 3 秒进入配网。
   - `PWR` 短按在正常显示与超级省电显示间切换；长按 3 秒进入超级省电。该模式只熄屏/降亮度，不断开 Wi-Fi 或语音能力。
   - PWR 按住 10 秒以上才允许 PMIC 硬件关机。
3. 重新运行按键契约、既有显示契约与 `idf.py build`。
4. 烧录真机后，以串口 `BOOT/PWR` 事件、OTA 请求、WebSocket 会话、音频上行、识别和语音下行逐项验收。

## 风险与回滚

- EXIO4 的有效电平以真机读取日志为准；若与原理图相反，仅反转读取判断，不改变业务语义。
- 不实现实体键恢复出厂，避免误清除 Wi-Fi、设备身份和 OTA 配置。
- 回滚仅恢复本板级文件的按键/PMIC寄存器设置；不影响其他板型。
